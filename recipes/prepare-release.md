Prepare the next release of this project.

1. Collect what changed since the last git tag and sort it into features, fixes and internal changes.
2. Propose the next version number following the project's versioning, and update it wherever the project keeps it.
3. Update the changelog or release notes, if the project has them, in the existing style.
4. Run every check the project has: tests, typecheck, lint, build.

Show me the version, the notes and the check results, and ask before creating the commit and the tag.
