Sort what is in inbox/.

Move each item to the folder in this project where it belongs, with a file name that starts with its date (YYYY-MM-DD). Extract deadlines, amounts and to-dos into tasks.md, with the date and a link to the file. If an item fits nowhere, leave it in inbox/ and say why.

Never delete anything. Conclude with what you filed where and the new tasks.
