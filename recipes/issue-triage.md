Triage the open issues of this project that have no reply yet. Use the `gh` CLI if it is installed and signed in; otherwise tell me that and stop.

For every new issue:
- Classify it: bug, feature request, question, or unclear.
- Check whether it duplicates an existing issue and name it if so.
- Find the code it relates to and say in one sentence what is probably going on.
- Draft a short, friendly reply that asks for what is missing or explains the next step.

Put everything in one document, newest issue first. Do not post anything on GitHub: I will review the drafts first.
