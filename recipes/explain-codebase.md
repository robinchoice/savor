Write the document a new developer should read on their first day with this project.

Cover: what the project does and for whom, how the code is organized and why, the main data flow from input to output, how to run it and run its checks, the conventions the code follows, and the places where things are tricky or easy to break.

Point at real files and functions. Keep it to what someone needs in the first week, not everything there is. Save it as a document in this project and link it.
