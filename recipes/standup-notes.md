---
title: Standup notes
blurb: Yesterday, today, blockers, written from the git history so you don't have to.
category: Daily routine
schedule: 0 9 * * 1-5
---
Write my standup notes from this project's git history and working tree.

- **Yesterday**: what the commits of the last working day did, grouped by topic, in one line each.
- **Today**: what is in progress (uncommitted changes, the current branch, unfinished TODOs) and the obvious next step for each.
- **Blockers**: failing checks, missing credentials, questions left open in code comments.

Plain language, no commit hashes. Five lines per section at most. Do not change any files.
