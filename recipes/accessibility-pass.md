Review the user interface of this project for accessibility. If the app runs locally, start it, open it in the preview and go through every screen; otherwise work from the source.

Check: everything reachable and usable with the keyboard alone, visible focus, labels on form fields and icon-only buttons, alt text on meaningful images, color contrast of text and controls, headings in a sensible order, error messages that say what to fix.

Fix what is unambiguous and commit it. List the rest with the screen, the element and what a fix would take.
