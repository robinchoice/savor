Report what was left lying around in this project. Only read, do not commit, push, stash or reset anything.

1. Run git status and git log @{u}..HEAD in the project folder and in each worktree (git worktree list). List uncommitted changes and unpushed commits.
2. Match them to conversations, open or completed, with list_conversations and read_conversation: which conversation made the change, and is it still working on it?
3. List conversations that wait for an answer from me, with their open question.

One line per item with a link to the conversation, grouped by: uncommitted, unpushed, waiting for me. Say what you would do with each. When there is nothing, say so in one sentence.
