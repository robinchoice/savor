This project is a Kontor: notes, administration and knowledge in Markdown files, not software. There is no code to build and no app to preview.

- README.md describes the folders and what goes where. Keep it current when you add a folder.
- New things land in inbox/. Filed things get a name that starts with their date (YYYY-MM-DD).
- tasks.md is the one list of to-dos and deadlines: `- [ ] YYYY-MM-DD what, link to the file`. Tick tasks off instead of deleting them.
- Never delete or overwrite a document. Move it, or write a new version next to it.
- This folder may hold personal data. Do not send its contents to services outside this computer unless asked to.
- Answer from the files and link them. Say so when something is not in them instead of guessing.
