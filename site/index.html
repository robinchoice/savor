Agents got fast. Keeping up with them didn't.

  1. One of your terminals is waiting for you.You find out which one when you happen to look.
  2. The answer is in there somewhere.Between tool calls, diffs and retries, the one sentence you needed scrolls past.
  3. Close the laptop and you're out.The agent keeps working, or keeps waiting. From your phone you can't tell.

What Savor does for you

It sits between you and your agents and turns their output into something you can act on.

1

Reports back

Each task gets a short acknowledgement and one result. Questions arrive as decisions with options, and you answer all of them in one reply. The raw output stays one click away in the activity log.

2

Shows the work

Whatever the agent builds runs in a live preview next to the conversation. You both use the same page. Point at an element, say what should change, and its selector travels with your message.

3

Works while you're away

Saved prompts run on a schedule and can be chained, from a daily digest to a release checklist. Pair your phone with a QR code and answer from anywhere, end-to-end encrypted.

Who it's for

You build with agents, not in terminals

  • Describe what you want in plain language
  • Get a result you can read, not a log
  • Watch the page while it is being built
  • Start from 22 ready-made workflows

You run many agents at once

  • One agent session per conversation, filtered by "Your turn"
  • A git worktree per conversation, merged back when done
  • Commit diffs and approvals inside the conversation
  • Switch agent or model mid-conversation

Savor costs nothing. It uses the Claude Code, Codex or OpenCode subscription you already have.

  • AGPL-3.0All of the source is on GitHub.
  • No accountNo cloud between you and your agents.
  • Plain filesConversations live in .savor/ inside your project.
  • Encrypted end to endPhone access goes through a relay that only sees ciphertext.

Savor is built by coding agents working inside Savor, with one person at Pleasance setting the direction. If it ever stops, you lose nothing: your code is in git, conversations are plain files, and Claude Code and Codex sessions resume without Savor. How Savor is maintained

Savor is early software. Known gaps are listed in the README.
