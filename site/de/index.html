Savor / Open Source · läuft lokal

Deine Agenten. Auf deinem Rechner.

Savor ist ein Arbeitsplatz für Claude Code, Codex und OpenCode, der dort läuft, wo dein Code liegt. Jede Aufgabe endet mit einem klaren Ergebnis und den Fragen, die dich brauchen. Ohne Konto und ohne eine Cloud von uns dazwischen.

So funktioniert's

Ein Gespräch pro Aufgabe. Es meldet sich, wenn es fertig ist.

Die Bilder zeigen die App auf Englisch. Auf einem deutschen Rechner spricht sie Deutsch.

01

Projektordner öffnen

Wähl Ordner auf deinem Rechner. Die Sitzungen von Claude Code und Codex, die dort schon liefen, erscheinen als Gespräche. Eine Übersicht zeigt, was in allen Projekten auf dich wartet.

In der App: Projekte → Beliebigen Ordner öffnen

02

Aufgabe übergeben

Beschreib sie in deinen Worten, wähl Agent und Modell. Du bekommst eine Zeile, dass es losgeht, und ein Ergebnis mit nächsten Schritten, wenn es fertig ist. Den Rohlauf gibt es einen Klick weiter, und ein Gespräch kann einen eigenen Git-Worktree bekommen.

In der App: + Neues Gespräch

03

Alle Fragen in einer Antwort

Fragen kommen als Entscheidungen mit Optionen und einer Empfehlung. Auswählen, kurz kommentieren, abschicken. Der Reiter „Für dich“ zeigt, welches Gespräch wartet.

In der App: Für dich → Antworten

04

Das Ergebnis in der Live-Vorschau

Was der Agent baut, läuft neben dem Gespräch, und ihr benutzt dieselbe Seite. Zeig auf ein Element, sag, was sich ändern soll, und sein Selektor reist mit deiner Nachricht.

In der App: Browser → Element auswählen

05

Weiter, während du weg bist

Gespeicherte Prompts laufen nach Zeitplan, vom nächtlichen Abhängigkeits-Check bis zur wöchentlichen Release-Checkliste. Koppel dein Handy per QR-Code und antworte von überall; das Relay dazwischen sieht nur Chiffretext.

In der App: Workflows · Geräte & Fernzugriff → Gerät koppeln

Deine Agenten sprechen mit Anthropic, OpenAI und anderen wie im Terminal: mit deinem Abo, nicht über uns.

  • AGPL-3.0Der ganze Quelltext liegt auf GitHub.
  • Kein KontoÖffnen, Ordner wählen, loslegen.
  • Klartext-DateienHört Savor je auf, verlierst du nichts.
  • KostenlosEs nutzt das Abo für Claude Code, Codex oder OpenCode, das du schon hast.

Robin (robinchoice) hat die Architektur entworfen, schreibt die Spezifikationen und prüft die Ergebnisse; den Code schreiben Coding-Agenten in Savor, diese Seite eingeschlossen. Ein wöchentlicher Check lässt Savor gegen die neuesten Versionen von Claude Code, Codex, OpenCode, Grok Build und Antigravity laufen, damit Änderungen an ihren Protokollen früh auffallen. Hört Savor je auf, verlierst du nichts: Dein Code liegt in Git, Gespräche sind Klartext-Dateien, und Sitzungen von Claude Code und Codex laufen ohne Savor weiter. Wie Savor gepflegt wird (englisch)

Die Desktop-App sendet einen anonymen Ping am Tag, damit wir wissen, wie viele Savor nutzen: eine zufällige ID, die auf deinem Rechner entsteht, die Savor-Version und die Plattform. Nichts über dich, deine Projekte oder deine Gespräche. Das Relay, das sie zählt, speichert keine IP-Adressen und löscht IDs, die es 90 Tage nicht gesehen hat. Abschalten kannst du ihn im Konto-Menü unter App-Einstellungen → Diese Installation mitzählen.

Savor ist junge Software. Bekannte Lücken stehen in der README (englisch).

Linux

chmod +x Savor-0.6.47.AppImage && ./Savor-0.6.47.AppImage

Oder in einer Zeile, die Savor auch ins App-Menü einträgt:

curl -fsSL https://savor.pleasance.org/install.sh | sh

macOS

Savor für Apple Silicon laden .dmg · etwa 130 MB · lieber für Intel-Macs

Von Apple signiert und notarisiert. Die App aktualisiert sich selbst. Oder mit Homebrew:

brew install --cask robinchoice/tap/savor

Das Installationsprogramm ist noch nicht signiert. SmartScreen fragt einmal nach.

npm install
npx playwright-core install chromium
npm start
